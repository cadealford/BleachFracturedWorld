# Game modding workflow

Use the Universal Modder skills for game-mod work:

- Start every new mod or game-integration task with `game-recon`.
- Use `mod-any-game` to plan and execute mod work.
- Use `asset-pipeline` or `fal-assets` for game-ready art.
- Use `game-automation` only after asking permission before controlling a game.
- Use `publish-mod` before packaging or sharing a mod.
- Use `share-field-notes` after verified work that would help future contributors.

Safety:
- Never bypass anti-cheat, DRM, or ownership checks.
- Do not modify saves, install loaders, drive input, or publish without explicit user approval.
- Prefer single-player/offline and official modding routes.
